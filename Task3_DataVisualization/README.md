
# CodeAlpha Internship - Task 3
## Data Visualization: Bike Sharing Dataset

### 1. Project Overview

This project focuses on visualizing bike-sharing
rental patterns using Python.

The objective is to transform raw data into meaningful
visualizations and identify useful insights about
customer behavior and rental demand.

### 2. Dataset

Dataset: Bike Sharing Dataset (hour.csv)

Number of records: 17,379

Number of columns: 17

The dataset includes hourly rental counts,
weather conditions, seasons, temperature,
humidity and customer categories.

### 3. Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### 4. Visualizations

The project includes:

1. Seasonal Rental Analysis
2. Hourly Rental Analysis
3. User Type Comparison
4. Weather Impact Analysis
5. Working Day Comparison
6. Rental Distribution Histogram
7. Seasonal Box Plot
8. Temperature Scatter Plot
9. Correlation Heatmap
10. Combined Bike Sharing Analytics Dashboard

### 5. Key Findings

- Peak average rental demand occurs at 5 PM.
- Lowest average rental demand occurs at 4 AM.
- Fall has the highest average seasonal demand.
- Registered users contribute approximately 81.17%
  of total rentals.
- Clear weather has the highest average rental demand.

### 6. Business Recommendations

- Maintain sufficient bike availability during peak hours.
- Plan resources according to seasonal demand.
- Improve registered customer retention.
- Consider weather conditions in operational planning.
